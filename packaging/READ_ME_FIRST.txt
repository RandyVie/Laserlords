LASER LORDS - native runner (unofficial, preview)
=================================================

This program plays the 1992 Philips CD-i game Laser Lords natively, without a CD-i
emulator or BIOS. It does NOT contain the game: you need your own copy as a disc image
(a MAME .chd file, or .cue + .bin).

Getting started
  macOS    Drag Laser Lords to Applications. First start: right-click the app, choose
           Open, then Open again (the app is not notarised by Apple).
  Windows  Run LaserLords.exe. If Windows shows "Windows protected your PC", click
           More info, then Run anyway (the exe is not code-signed).
  Linux    Run ./laserlords (Steam Deck: add it to Steam as a non-Steam game with the
           disc image path as launch option).
  Switch   Needs custom firmware with the Homebrew Menu. Copy the "switch" folder from
           this zip to the root of the SD card, put your disc image in
           sdmc:/switch/laserlords/ and start Laser Lords from the Homebrew Menu.

On first start the app asks for the disc image and shows the controls.

Controls
  Move / walk        mouse, arrow keys / WASD, left stick / D-pad
  Button 1           left click, Space, Enter, Z, gamepad A   (select, talk, act, skip)
  Button 2           right click, X, Backspace, gamepad B
  F1 help, F2 scaling, F3 borders, F4 slower planets, F11 or Cmd/Ctrl+Enter fullscreen,
  Cmd/Ctrl+Q quit.   Switch: - = borders, + = quit.

Status
  This is a preview: all planets have been visited, but the game hasn't been tested
  extensively yet. The app records nothing about you and has no internet access.
